# GPX Track Overlay — Инструкция без терминала

---

## Часть 1. Размещение кода на GitHub

### Шаг 1. Создайте аккаунт на GitHub

Если аккаунта ещё нет — зарегистрируйтесь на [github.com](https://github.com). Достаточно бесплатного плана.

### Шаг 2. Создайте новый репозиторий

1. Нажмите зелёную кнопку **«New»** в левом верхнем углу главной страницы GitHub
2. Заполните поля:
   - **Repository name:** `gpx-track-overlay`
   - **Description:** `GPX трек → STL для 3D-печати` (необязательно)
   - Выберите **Public**
   - Поставьте галочку **«Add a README file»**
3. Нажмите **«Create repository»**

### Шаг 3. Загрузите файл компонента

1. Откройте только что созданный репозиторий
2. Нажмите **«Add file» → «Upload files»**
3. Перетащите файл `gpx-track-overlay.jsx` в зону загрузки
4. Внизу страницы нажмите **«Commit changes»**

### Шаг 4. Создайте файл index.html

Приложению нужна HTML-обёртка. Создайте её прямо на GitHub:

1. Нажмите **«Add file» → «Create new file»**
2. В поле имени файла введите: `index.html`
3. Вставьте в редактор следующий код:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>GPX Track Overlay</title>
</head>
<body>
  <div id="root"></div>
  <script type="module">
    import React from 'https://esm.sh/react@18'
    import ReactDOM from 'https://esm.sh/react-dom@18/client'
    import App from './gpx-track-overlay.jsx'

    ReactDOM.createRoot(document.getElementById('root')).render(
      React.createElement(React.StrictMode, null,
        React.createElement(App)
      )
    )
  </script>
</body>
</html>
```

4. Нажмите **«Commit changes»** → **«Commit directly to the main branch»** → **«Commit changes»**

## Часть 2. Публикация через GitHub Pages

GitHub Pages бесплатно публикует ваш код как сайт — никакого сервера не нужно.

### Шаг 1. Откройте настройки репозитория

Нажмите вкладку **«Settings»** (иконка шестерёнки) в верхнем меню репозитория.

### Шаг 2. Включите Pages

1. В левом меню найдите раздел **«Pages»**
2. В блоке **«Branch»** выберите ветку **`main`** и папку **`/ (root)`**
3. Нажмите **«Save»**

### Шаг 3. Дождитесь публикации

GitHub соберёт сайт за 1–3 минуты. Обновите страницу — вверху появится зелёный баннер с адресом вида:

```
https://ВАШ_ЛОГИН.github.io/gpx-track-overlay/
```

Перейдите по этой ссылке — приложение готово к работе.

> Адрес можно сохранить в закладках и открывать с любого устройства, где есть браузер.

## Часть 3. Работа с приложением

После открытия ссылки вы увидите интерфейс с боковой панелью слева и картой справа.

---

### Шаг 1. Получите GPX-файл тренировки

GPX — стандартный формат трека. Скачать его можно из большинства спортивных сервисов:

**Strava:**
Откройте тренировку на сайте strava.com → в правом меню нажмите на три точки **«...»** → **«Экспортировать GPX»**

**Garmin Connect:**
Откройте тренировку → кнопка с тремя точками **«...»** → **«Экспортировать в GPX»**

**Komoot / AllTrails / Wikiloc:**
На странице маршрута найдите кнопку **«Скачать»** и выберите формат **GPX**

---

### Шаг 2. Загрузите файл в приложение

В левой панели под надписью **«GPX-файл»** есть зона загрузки.

Два способа:
- Перетащите `.gpx` файл мышью прямо на эту зону
- Кликните по зоне и выберите файл через диалог

После загрузки панель покажет:
- Имя файла с зелёной галочкой
- Количество точек трека
- Дистанцию в километрах
- Координаты центра

На карте справа появится линия трека. Зелёная точка — старт, красная — финиш. Штриховая рамка показывает, что войдёт в область печати A4.

---

### Шаг 3. Настройте параметры модели

Четыре ползунка позволяют точно подобрать размеры под ваш принтер и задачу:

**Отступ карты** (5–25%)
Пустое пространство вокруг трека до края листа. При 10% трек занимает большую часть листа. Увеличьте до 15–20%, если хотите больше контекста вокруг маршрута.

**Ширина трека** (0.6–3.0 мм)
Толщина рельефной линии на распечатанной модели. Рекомендации:
- Городской бег, ровный маршрут → 1.0–1.2 мм
- Трейл, горы, сложный рельеф → 1.6–2.0 мм
- Хочется заметный рельеф → 2.5–3.0 мм

**Высота трека** (2–10 мм)
Насколько линия возвышается над подложкой. 5 мм — оптимально: хорошо ощущается пальцем и не слишком хрупко. При 2–3 мм модель тонкая и лёгкая, при 8–10 мм — выразительная, но требует больше материала.

**Толщина подложки** (1–3 мм)
Толщина плоской пластины-основания. 1.5 мм достаточно для большинства случаев. 2–3 мм если хотите жёсткую и тяжёлую модель, которая не гнётся.

Все изменения сразу отображаются на превью.

---

### Шаг 4. Сгенерируйте и скачайте STL

Нажмите кнопку **«Сгенерировать и скачать STL»**.

Прогресс-бар пройдёт четыре этапа за несколько секунд. По завершении файл `название_трека_3d.stl` автоматически скачается в папку загрузок вашего компьютера.

В левой панели появится блок **«Результат STL»** с тремя цифрами:
- Размер модели в мм — именно таким получится отпечаток
- Масштаб карты — например, 1:8 500 означает, что 1 мм модели = 8.5 метров в реальности
- Количество треугольников — техническая информация о сложности модели

---

### Шаг 5. Получите карту с terraink.app

Это самый важный шаг для точного совмещения. Карта должна быть с того же сайта и с теми же параметрами, что и ваша модель.

1. В секции **«Карта с Terraink.app»** нажмите на ссылку — она откроется в новой вкладке
2. Сайт откроется уже с правильными координатами и масштабом для вашего трека
3. На сайте нажмите кнопку скачивания карты
4. Выберите формат **A4, портретная ориентация**
5. Скачайте файл

## Часть 4. Печать и совмещение

### Печать карты

Откройте скачанный файл карты и распечатайте его со строгими настройками:

- Размер бумаги: **A4**
- Масштаб: **100%** (или «Фактический размер», «Без масштабирования»)
- Ориентация: **Книжная (портретная)**

Важно: большинство программ по умолчанию включают «Вписать на страницу» — это нужно обязательно отключить, иначе карта напечатается чуть меньше и модель не совпадёт.

### 3D-печать модели

Откройте файл `.stl` в вашем слайсере (Cura, PrusaSlicer, Bambu Studio или любом другом).

Рекомендуемые настройки:

| Параметр | Значение |
|---|---|
| Высота слоя | 0.15–0.2 мм |
| Заполнение | 15% |
| Поддержки | Не нужны |
| Адгезия к столу | Юбка или брим |
| Материал | PLA (проще всего) |

Разместите модель плоской стороной вниз — трек смотрит вверх. Поддержки не нужны, геометрия простая.

### Совмещение

1. Положите распечатанную карту на стол
2. Возьмите готовую модель и положите её треком вверх на карту
3. Север на модели всегда смотрит вверх — ориентируйтесь по сторонам листа
4. Линия трека должна точно лечь поверх маршрута на карте

## Часть 6. Возможные проблемы

**Файл не загружается в приложение**
Убедитесь, что расширение файла именно `.gpx`. Форматы `.fit` (Garmin) и `.tcx` не поддерживаются — конвертируйте их на сайте [gpx.studio](https://gpx.studio) (бесплатно, в браузере).

**На карте ничего не нарисовалось**
В GPX-файле могут быть только waypoints без трека. Откройте файл на [gpx.studio](https://gpx.studio) и проверьте, есть ли линия маршрута.

**Трек занимает меньше половины листа**
Уменьшите отступ карты до 5–7%. Если трек всё равно маленький — маршрут слишком короткий или охватывает слишком большую область. Обрежьте лишнее на [gpx.studio](https://gpx.studio).

**Модель не совпадает с картой при наложении**
Почти всегда причина — карта напечатана с масштабированием. Убедитесь, что при печати выбрано «100%» или «Фактический размер».

**Сайт не открывается после включения Pages**
Подождите 3–5 минут и обновите страницу. Если не помогает — проверьте в настройках Pages, что выбрана ветка `main` и папка `/ (root)`.

**Браузер блокирует скачивание STL**
Некоторые браузеры спрашивают разрешение на скачивание нескольких файлов подряд. Разрешите загрузки с вашего github.io-домена в настройках браузера.

---

*Все файлы обрабатываются локально в вашем браузере. GPX и STL никуда не передаются.*
